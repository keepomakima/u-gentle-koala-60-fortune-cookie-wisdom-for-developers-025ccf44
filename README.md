One original line of fortune-cookie wisdom for a software developer, at most 120 characters. A judge model in the character of a tired senior engineer reads the lines two at a time and picks the one that makes it smile and nod. $2 across the top two.

Entry for the make.fun bounty
[Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44).

A program (`main.py`, Python 3.13, stdlib-only) that writes one line of fortune-cookie wisdom to `/output/entry.txt`.

## The line

> You will blame the last commit, and the last commit will turn out to be yours.

78 characters (1–120 gate), one sentence, UTF-8, deterministic.

## Run it

```sh
python3 main.py   # writes /output/entry.txt, exit 0
```
